### Detailed Findings by Severity

- **[P1] "Replying to" link marked by colour alone**
  - Location: `apps/web/src/features/tweets/components/ReplyingTo.tsx`
  - Category: Accessibility · WCAG 1.4.1 (axe `link-in-text-block`, serious; 1.07:1 against the surrounding faded text)
  - Impact: users who cannot tell the blue from the grey cannot see the handle is a link.
  - Recommendation: underline at rest, medium weight, as DESIGN.md's link rule. **Fixed.**
- **[P2] Two unnamed complementary landmarks on desktop**
  - Location: `app/layout/Sidebar.tsx`, `app/layout/RightPanel.tsx`
  - Category: Accessibility (axe `landmark-unique`)
  - Impact: screen-reader landmark lists show two identical "complementary" regions.
  - Recommendation: the rail becomes a plain container (its "Primary" nav is the landmark); the right panel is named "Search people". **Fixed.**
- **[P2] Two buttons named "Reply" on the conversation page**
  - Location: `features/tweets/components/ReplyButton.tsx`
  - Category: Accessibility (WCAG 2.4.6 good practice)
  - Impact: voice-control and screen-reader users cannot tell "go to the reply box" from "send the reply".
  - Recommendation: name the icon "Write a reply". **Fixed.**
- **[P3] Avatars not lazy-loaded** — `components/ui/Avatar.tsx`; Performance. **Fixed** (`loading="lazy"`, `decoding="async"`).
- **[P3] Field hints leave one word on the last line** — `components/ui/Field.tsx`; detector `straggler`. **Fixed** (`text-wrap: pretty`).
- **[P3] Phone with 200% text overflows** — chirp action row and header icons; Responsive. Beyond WCAG 1.4.4/1.4.10 (both pass). **Known limitation.**
- **[P3] 401 logged in the console when signed out** — the session check `GET /auth/me`; by design. **Known limitation.**

### Patterns & Systemic Issues
- Links outside running text use hover-only underlines (author names, profile counts, notification names). They pass today because weight or position marks them; any new link set inside faded running text must follow DESIGN.md's always-underlined rule.

### Positive Findings
- Skip link first in tab order; logical order; visible focus on every control; native dialogs move focus in, close on Escape and return focus.
- No horizontal overflow on any screen at 375 / 768 / 1280, and none at 320 px or with 200% text at 768 and 1280.
- No contrast failures in light or dark; field borders meet 3:1.
- Every image has alt text; the floating compose button never covers a control at the end of a list.
- Route-level code splitting; chirp images lazy-loaded; `content-visibility` on feed rows.
